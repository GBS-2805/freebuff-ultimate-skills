# UI Design

## Understand the brief
Identify the user, their goal, platform, key tasks, constraints, and success criteria before proposing screens.

## Design principles
- Prioritize clear hierarchy, readable typography, consistent spacing, and obvious actions.
- Make the primary action easy to find without hiding important secondary actions.
- Use familiar patterns and consistent components.
- Design empty, loading, error, success, disabled, and focus states—not only the ideal state.
- Keep layouts responsive and content legible at small screen sizes.
- Use accessible contrast, labels, keyboard navigation, and sufficiently large touch targets.

## Workflow
1. Map the user journey and identify friction.
2. Establish information architecture and content hierarchy.
3. Define reusable components and interaction states.
4. Create a low-fidelity structure before visual polish.
5. Check mobile and desktop behavior.
6. Review edge cases and accessibility.
7. Explain design decisions and unresolved assumptions.

Avoid decorative complexity that makes the task harder. Do not invent user research or claim usability testing occurred unless it did.
